# 交付验收门槛

## 原谱与转调

- 所有源页已看过，所有小节、反复、房子、歌词轮次有对应；源小节与演奏小节编号可追溯。
- 全部源音事件有出处，没有凭空生成的伴奏；图例/和弦标签冲突和修正留有证据；unresolved 为空。
- 保留弦/品、声部数量、拍点、时值、休止、装饰奏法、箭头方向与实际范围。截图逐音核对属于视觉/音乐判断，结构脚本不能代替。
- 每音满足 source MIDI + 实际移调半音 + 12×显式八度调整 = target MIDI = 标准空弦 MIDI + 相对夹品位 + 目标 Capo。
- 指法图完整匹配和弦音类和 slash 低音；基础图、旋律变化、扫弦实际声部关系清楚。手指跨度和连奏的物理可行性实际检查。

## 交互与声音

运行 browser_qa：离线零网络请求、零 JS 错误；所有小节和和弦图存在；扫弦是箭头而非 picking 数字；Chrome/WebKit 实际播放、暂停清理、模式切换、BPM 更新、段落定位和循环回跳；320/390/600/900/1440 宽度页面与谱行均不横溢，窗口变化自动重排每行小节数，短音/多和弦/歌词仍可读，定位和游标保持对齐；原谱模式和目标模式共用数据。

实际点击音符/箭头/歌词/空白立即播放、Option/Alt 试听、电脑媒体键/空格与系统 Media Session play/pause 回调、拖动进度、从中途播放、切换升调段、循环、窗口隐藏。暂停/跳转/模式切换不会留下旧声源继续响。相邻连续的击勾弦、滑音等特殊技术要额外检查，默认模板未覆盖的声学实现先扩展。

音频自动检查包括真实 OfflineAudioContext 每个目标音的频率、有限数值、非零 RMS 和无削波。新曲还要用 `guitarScore.renderAudio()` 跑整首或有风险的段落，检查有音的小节能量和全曲峰值；明确休止小节应允许静音，不能照搬《仓颉》的“每小节都出声”。全曲音频数据较大，可逐段测试。若能实际听，试听 picking/扫弦/延音/转位/升调；若只有数值证据，报告“自动音频检查”，不能写“已人耳试听通过”。

主旋律默认关闭，开启后独立混音、关闭恢复伴奏；按数据检查两模式音高、八度、临时变音、休止与跨小节延音。实际 OfflineAudioContext 检查旋律频率及整曲两模式混音有限值、RMS、峰值；从持续音中间进入、循环边界、播放中切换开关/模式/BPM/窗口与暂停清音均需覆盖。没有旋律的输入不得编造旋律。

主旋律须用已署名的真实钢琴录音；检查缓存原始/导出哈希、根音映射与实际音高、解码错误、起音及自然衰减。松键尾音短且无硬切；从延音中间进入采用采样偏移。关闭主旋律后的伴奏音频与旧版本逐样本在解码数值容差内一致，并核对吉他采样与数据未变。

## 节奏图形

运行 rhythm_qa.cjs：检查符梁数量、第二/第三层连续性、混合时值短符梁、附点和孤立符尾。实际 DOM 不得同时保留事件短横线与分组符梁；密集的三十二分组必须有完整第三层，单个十六分的第二层不得跨过八分音符。截图与 PDF 逐个对照至少一组八分、一组十六分、一组三十二分和混合节奏；附点四分也要有附点。

## 打印

从手机宽度进入打印，确认独立纸谱分行恢复，退出打印恢复屏幕布局。运行 print_qa，核对 A4 页数与打印 DOM。查看所有页缩略图，放大首段、密集节奏、最多和弦变化、升调段和最后一页。无字/图/箭头编号相碰、无跨页断行、无截断、无空白溢出页；字体与中文歌词在实际纸张大小下可读。默认 3 小节×4 行，密集行可以 2 小节；用户偏好优先，必要时调整分行分组和上下空白，不能只整体缩小字号。临时 print PDF 留 work/，用户未要求时不额外交付它。
