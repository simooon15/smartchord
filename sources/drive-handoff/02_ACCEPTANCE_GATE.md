# 验收 Gate（Codex 必须完成后才能交付）

## Gate A：原谱转录（最重要）

- [ ] 完整覆盖截图所示全部内容，首小节至终止小节连续且无重复，截图之间的重叠段正确去重。
- [ ] 每小节和弦图、斜杠低音、拍号、变调位置、分解和弦/独立音符/扫弦方向逐一核对。
- [ ] `×` 按 **和弦对应的弦位音** 还原，不再产生闷音；不将 chord diagram 的禁止弹弦符号误作正常音。
- [ ] 原谱 C→D 升调段与目标 G→A 指法段匹配。
- [ ] 所有数字品位对照绝对音高，G 指法目标 -5 个半音（相对无变调夹），Capo 2 实际 -3 个半音（原谱不夹）；实际音高偏差必须有显式且可理解的例外清单。
- [ ] 原主旋律的音程和节奏关系保留；低音行进、和弦根音/转位没有被不合理改变。
- [ ] 主要小节可以从截图追到 source-to-score 记录，没有“复制模板即视为转录完成”的占位。

## Gate B：交互与声音

- [ ] 全曲可播放，定位、暂停、重播、变速、循环、分段跳转、跟随高亮都可操作。
- [ ] 播放/可见谱面由同一 score 模型产生，音符位置、音高、时值同步。
- [ ] 变调夹真实计入实际发声音高，原调切换（如保留）与新调区分清楚。
- [ ] 点击单音听音，和弦 `×` 对应正常吉他拨弦，扫弦表现为有先后次序的真实和弦声。
- [ ] Desktop Chrome / iOS Safari 或等效 WebKit 基本检验，控制台无报错；单 HTML 离线 file:// 打开不依赖外部文件。

## Gate C：打印/PDF

- [ ] 有一个明显的「打印 / 导出 PDF」按钮，可调用浏览器原生打印。
- [ ] A4 实测 PDF 逐页检查；封面/标题不要大到挤压谱行；每行 2–4 小节自适应；无小节或六线谱系统跨页被截断。
- [ ] 和弦名、六线、节奏、品位、歌词清楚且不重叠，无页边截断、横向溢出。
- [ ] 控件不打印；黑白打印依然易读，有页码和小节号。

## Gate D：交付纪律

- [ ] **最终用户仅收到一个 HTML 文件**，其他 QA 和中间工作文件只在 Handoff 文件夹留档。
- [ ] QA_REPORT 列出功能测试及音乐校对覆盖度，明确任何仍不能核实的部分。未通过 Gate A 不得声称全谱完成。
- [ ] 不未经请求推送 GitHub，不修改用户其他项目。
